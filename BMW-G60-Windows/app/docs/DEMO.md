# Seven-minute demonstration

1. **Overview — establish the cohort (45 seconds).** Open G60 / US / all powertrains / supplied-unverified origin. Show 3,610 distinct records, unknown feedback dates and provisional mapping coverage. Explain that mapping coverage is not accuracy or confidence.
2. **Requirements — inspect a need (60 seconds).** Search “Touch screen, operation.” Show 28 / 3,610 unmet-need records, an Unscored impact band, and separate positive observations. Change the category filter to demonstrate that the denominator stays fixed. Critical flags elsewhere route to expert review.
3. **Evidence — trace a quotation (45 seconds).** Open an original row. Point out workbook, sheet, row, source checksum and retained tags. Open the PDF source explorer to show German-market catalog candidates awaiting review. A blank equipment cell remains Unknown.
4. **Web connector — add observed evidence (45 seconds).** Use Connect web evidence with one seeded public page or a prepared test URL. Show that the saved static HTML snapshot is labeled Observed web evidence, that no crawling occurs, and that keyword mappings enter review before affecting the default supplied-data view.
5. **AI — replay with provenance (45 seconds).** Before editing the requirement, press Replay analysis. Show model, original generation time, eight-record sampling, quotations and uncertainties. Explain that live mode is an explicit server-key action. Other inputs cannot reuse this replay.
6. **Decision — record judgment (60 seconds).** Edit the desired behavior with a rationale. The new revision returns to Proposed / Unscored. Approve it, select an impact band with a rationale, then inspect the revision and decision history. In a presentation rehearsal, use an isolated database and label the rationale as a rehearsal.
7. **Comparison and export (65 seconds).** Show the purple hypothetical competitor scenario. Explain Not comparable until the BMW cell has a reviewed compatible fact. Export the board deck, then open its immutable JSON snapshot from Executive exports. The deck contains approved requirements and source citations; fictional competitors remain in its appendix.

For an offline presentation, install dependencies and import the sources in advance. Start the app before disconnecting external networking. Local assets, original source files, saved web snapshots, SQLite search, the supplied matching replay and PowerPoint export all remain available. Avoid selecting Live AI or connecting new web evidence while offline; failed live jobs stay visible and can be retried explicitly.

The demo never claims the proposed requirements, customer origin, feature mappings, engineering causes, costs, ROI or competitor values have been verified. Human labeling and PM review are visible next steps.
